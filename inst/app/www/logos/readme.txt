This subdirectory contains the logos for all partners. 

If you wish to update a logo, just swap the current version for the new, and make sure it has the correct .png title, i.e. one of the following:

dmp.png
ne.png
bto.png
blackbawks.png

If you wish to add another partner, refer to utils_ui_helpers.R, where the function logolink() can be modified to add another partner.
