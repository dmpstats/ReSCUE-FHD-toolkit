# Flight Height Distribution

This section displays visualizations of the selected flight height distribution (FHD) data.

## Overview

The flight height distribution plot shows the probability distribution of bird flight heights across your selected datasets. Each FHD is represented as a separate line or series on the plot.

## Features

- **Multiple datasets**: Compare FHDs from different species, methods, or seasons simultaneously
- **Legend**: Toggle the legend visibility using the "Hide legend" switch to improve readability
- **Interactive**: Hover over the plot to see detailed information about specific data points

## Customization

You can customize what data is displayed by:
- Adjusting covariate selections in the "Selected Data" panel
- Toggling the legend on or off using the switch in the card header

## Risk Zone Display

The plot includes shaded regions representing the turbine rotor swept area (minimum and maximum rotor heights). These help visualize the overlap between bird flight distributions and collision risk zones.
