# Data Selection Help

In this tab, you can select flight-height distributions for analysis in one of three ways:
- <b>Map Selection:</b> Select a flight-height distribution suitable for your area from a map of existing flight-height studies.
- <b>Table Selection:</b> Select a flight-height distribution from a table of pre-existing flight height distributions. Unlike the above, these might not be tied to a specific region.
- <b>Data Upload:</b> If you have a specific flight-height distribution from elsewhere, you can upload it for analysis.
