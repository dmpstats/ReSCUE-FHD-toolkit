# Data Selection Help

In this tab, you can explore the **flight-height distributions** made available through the ReSCUE project and select the distribution that best fits your specific case. 

The ReSCUE project has a wide variety of flight-height distributions for different avian species and regions. The map tool below will help you explore the available distributions.

# Map Selection

Use the filters below the map to find a flight-height distribution suitable to your specific case. Filter by species and any other filters that you may find relevant. The map will update to show the available distributions that match your filters.

Some distributions contain **additional covariates** for further analysis, such as wind-speed or temperature. These are provided for the user to explore the effect of some of these covariates on flight-height distributions. If you are interested in exploring these covariates, please select a distribution that contains them.

You can select up to 10 different distributions to explore. Once you have selected the distributions, click the **Next** button to proceed to the next step.

**Warning:** These additional covariates are not intended for use with the **Stochastic Avian Collision Risk Model (SCRM)!** If you are using this tool to generate SCRM input data, please select a different distribution that does not contain additional covariates.

# User Upload

If you have a pre-prepared flight-height distribution, created through ReSCUETools, that you want to upload, use the **Upload** button in the bottom-right.
