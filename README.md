# ReSCUEApp

A Shiny application for exploring and comparing seabird flight height distributions (FHDs) across UK waters, developed as part of the **Reducing Seabird Collisions Using Evidence (ReSCUE)** project - an initiative funded by The Crown Estate's Offshore Wind Evidence and Change (OWEC) Programme.

## What it does

- Browse and filter FHDs by species, season, method, and region via an interactive map
- Compare multiple distributions and visualise collision risk height envelopes under user-defined turbine parameters (air gap, rotor radius)
- Upload your own FHD data alongside the built-in database
- Download results - including FHD plots, SCRM-ready data, and metadata - as a zip file

## Who it's for

Offshore wind developers, environmental consultants, conservation bodies, regulators, and researchers working on seabird collision risk assessment.
